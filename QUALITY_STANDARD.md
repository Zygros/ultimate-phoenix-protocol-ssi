# Repository Quality Standard

This repository is the public flagship prototype and follows explicit evidence boundaries.

## Canonical status labels
**Implemented** — documented runnable behavior.  
**Prototype** — partial/local/stubbed/not hardened.  
**Designed** — architecture without sufficient implementation evidence.  
**Historical** — preserved source material.  
**Verified** — independently inspectable evidence.  
**Unverified** — retained pending evidence.

## Release gate
No production, security, performance, AGI, autonomy, or independent-verification claim should be presented as established without a reproducible artifact or independent evidence record. Never commit credentials or private keys. Keep historical claims clearly separated from present capability.
