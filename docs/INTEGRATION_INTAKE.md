## Recommended Public Architecture

The repository and web application should use four visibly distinct layers. The **Implemented** layer contains source code, tests, deployment instructions, and reproducible commands. The **Planned** layer contains roadmaps and issue-tracked work. The **Conceptual** layer preserves philosophical models, symbolism, and exploratory frameworks. The **Evidence** layer stores hashes, attestations, source links, build logs, and external verification receipts.

This separation protects the work’s credibility: it preserves the creative and philosophical intent while making it easy for any visitor to determine what they can run today, what requires configuration, and what remains a hypothesis.
